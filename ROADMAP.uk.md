# Що далі: до справжнього синхронного перекладу

Режим за клавішею працює добре (~0,6–0,8 с від відпускання до мови перекладу). Синхронний режим
(`Start-StreamVoice.bat`) — робочий прототип. Нижче — чим ми ще не задоволені, що заміряли і що спробували б далі.
Цифри — з пари українська → англійська, RTX 4070 12 ГБ і живих тестів одного мовця.

[English version](ROADMAP.md)

## Куди йдуть ~3,5 с старту

Медіана від початку фрази на живому мовленні: перший прохід розпізнавання 0,9 с → перше підтверджене українське слово
1,5 с (+0,6) → **перше англійське слово 3,5 с (+2,0)** → перший звук 3,9 с (+0,4; самій моделі голосу треба 0,32 с).

Половина — перекладач: звичайні перекладачі змінюють переклад початку, коли приходять нові слова («А ні, я сказав» →
"Oh no, I said"; з «навпаки» → "No, I said the opposite"), тож англійська виходить лише тоді, коли ~4 українські слова
дають однаковий початок у двох перекладах поспіль, мінус 2 притримані слова.

## Відкриті проблеми та ідеї

### Затримка старту (мета: ≤ 2 с)
- [ ] **Перекладач, навчений на незакінчених реченнях** (prefix-to-prefix, «синхронне» донавчання). Для пари
  українська→англійська станом на листопад 2026 такого немає. Дешевий рецепт: пари «префікс → спільний початок його
  перекладу й перекладу цілого речення», LoRA на Hy-MT2-1.8B або 4B-LLM.
- [ ] **LLM-перекладач з інструкцією «текст може бути незакінченим, не домислюй»** — так зробив переможець IWSLT 2026
  (Parakeet + звичайна LLM + узгодження спільного початку); варто перевірити симуляцією слово за словом на Hy-MT2-7B.
- [ ] **Узгодження без розділових знаків** — Parakeet між проходами то ставить, то прибирає коми («Так, ну» ↔ «Так ну»),
  переклади розходяться, і перше слово може чекати 4+ с. Стосується ~кожної четвертої фрази.
- [ ] Готові переклади для слів-зв'язок на початку («так», «ну», «коротше» → "so", "well", "anyway").
- Спробувано й відкинуто: перерахунок кожні 0,25 с замість 0,5 (−0,25 с, але переклад розійшовся з перекладом цілої
  фрази на 26% проти 20%); притримувати 1 слово замість 2 (−0,25 с, губилися/дублювалися слова на стиках); AlignAtt на
  увазі quickmt (та сама крива «раніше ↔ гірше»); ніколи не відкликати підтверджене (закріплювало помилки ранніх
  проходів: 32% розбіжності).

### Розпізнавання
- [ ] **Донавчання Parakeet на голосі користувача** — 1–2 год власного мовлення, записаного для цього, з виправленими
  текстами (сторінка «слухаю — правлю»); має прибрати систематичні помилки («не»→«на», «Та ні»→«Тані»).
- [ ] **Зісковзування мови** — Parakeet іноді пише українську мову російською чи польською («Обережно, за тим будинком» →
  «Obereżne za tym budynkiem»), частіше на коротких проміжних проходах. Запасна суто українська модель (NeMo
  FastConformer uk) це виправляла, але вмикалася й від англійських слів (QuickMT, "in this spirit") і розпізнавала
  гірше — тому вимкнена. Кращий тригер: лише суто російські / польські літери, а не латиниця загалом.
- [ ] fp32-експорт Parakeet Ultra для відеокарти (int8 Ultra на CPU вже кращий за v3 fp32 на GPU).
- [ ] Справді потоковий український розпізнавач рівня Parakeet. Nemotron 3.5 ASR Streaming заміряно: 18–25% WER на
  голосі користувача проти ~8% у Parakeet за виграш лише 0–0,5 с — відкинуто. Варто стежити за об'єднаними
  потоково-офлайновими моделями NVIDIA (поки лише NeMo, Linux).

### Голос у синхронному режимі
- [ ] **Чутні стики** — кожен шматок до коми — окрема генерація з власною інтонацією. Ідеї: генерувати наступний шматок
  із попереднім як звуковим контекстом; менше, але довших шматків, де дозволяє затримка.
- [ ] **Голос відстає на довгих монологах** — англійська приблизно така ж довга, як українська, тож відставання росте;
  прискорення (≤1,3× — стеля для слухача) допомагає лише частково. Варіант — коротший переклад («стискати, перекладаючи»).
- [ ] Вигуки («Mm-hmm», «Hmm») змушують quickmt вигадувати продовження («Mm-hmm is a good idea»): пропускати їх без
  перекладу, обмежити довжину перекладу.

### Ігри та ресурси
- Заміряно в Path of Exile 2: повний режим поруч із грою генерував мову у 8–20 разів повільніше за реальний час
  (відеопам'ять переповнена, пріоритет у гри); легка розкладка (розпізнавання й переклад на процесорі — тепер типова для `Start-VoiceTranslate.bat`) — 1,07–1,10× швидше
  за реальний час із голосом 1.7B (перший звук 0,6–1,0 с) і 1,1–1,3× з 0.6B (0,55–1,3 с); гра 80–90 FPS (130–145 без
  нього), заміряно під час бігу без важких ефектів.
- [ ] Поруч із грою в голосу малий запас (1,07–1,3×): коли генерація стає повільнішою за реальний час, збирати фразу повністю
  й програвати цілою, а не уривками.
- [ ] Голос тримає відеокарту зайнятою ~88% часу під час мовлення (~третина потужності): обмеження навантаження
  (напр. 70%) для ігор.
- [ ] Менше відеопам'яті: fp16-експорт Parakeet (~1,2 ГБ замість 2,4).
- Спробувано й відкинуто: Hy-MT2-30B-A3B з експертами в оперативній пам'яті (якість 7B за ~1,9 ГБ відеопам'яті, але
  1,1–2,4 с на фразу); спекулятивне декодування з чернеткою 1.8B (повільніше: перевірка дорога, коли експерти в RAM).

### Продукт
- [ ] Розпізнавати, що співрозмовник перебиває (програма не чує дзвінок) — поки є клавіша «замовкни».
- [ ] Установник в один клік; підтримка Linux.
- Інші пари мов: задаються в `.env` (`VT_SOURCE_LANG` / `VT_TARGET_LANG`, див. README → Мови); коротко перевірено
  uk→de, uk→fr, en→de.
- [ ] Модель голосу, що говорить українською (у Qwen3-TTS 10 мов без неї), — для англійська → українська.
- [ ] Заміряти якість і швидкість на інших парах; синхронний режим для китайської / японської / корейської на виході
  (без пробілів між словами).
- [ ] Повідомлення програми й англійською (зараз лише українською); тестові фрази для розпізнавання інших мов.
